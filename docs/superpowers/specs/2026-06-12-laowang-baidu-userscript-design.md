# 老王论坛百度网盘油猴脚本设计

## 背景

目标是在老王论坛帖子页增加一个双站点油猴脚本，提升资源帖阅读效率，并在用户已登录论坛和百度网盘的前提下，完成购买确认、百度分享链接提取和自动保存到百度网盘。

已分析目标帖：

- URL: `https://laowang.vip/forum.php?mod=viewthread&tid=2821033`
- 论坛系统: Discuz! X3.4
- 当前帖子标题: `大美女【SkylarBlue】完美臀，超模身材`
- 下载方式: `百度盘`
- 来源: `自行打包`
- 文件数量: `41V 74P`
- 资源大小: `4.58G`
- 解压密码: `上老王论坛当老王`
- 未登录状态: 正文显示“本帖子中包含更多资源，您需要登录才可以下载或查看”

## 用户前提

- 用户会自行在 `laowang.vip` 登录论坛账号，脚本不处理论坛登录。
- 用户会自行在 `pan.baidu.com` 登录百度网盘账号，脚本不处理百度登录。
- 脚本不保存账号密码。
- 如果任一站点未登录，脚本只提示用户登录，不尝试自动登录。

## 范围

本版本实现双站点油猴脚本，匹配：

- `https://laowang.vip/forum.php?mod=viewthread*`
- `https://laowang.vip/thread-*`
- `https://pan.baidu.com/*`

论坛页负责信息增强、购买确认和任务创建。百度网盘页负责填提取码、创建目录并保存资源。

不实现以下能力：

- 不绕过论坛登录。
- 不绕过资源购买。
- 不破解隐藏内容。
- 不替用户自动输入账号密码。
- 不对非百度网盘链接做跨盘转存。

## 论坛页体验

脚本在主楼上方插入增强面板，展示：

- 清洗后的帖子标题。
- 作者、发布时间、板块。
- 下载方式、来源、文件数量、资源大小、解压密码。
- 当前状态：未登录、未购买、已购买、已提取链接、已保存、保存失败。

图片预览采用用户确认的 A 方案：

- 顶部显示 1 张主预览图。
- 下方显示缩略图列表。
- 点击缩略图切换主图。
- 点击主图打开灯箱预览。
- 未登录或图片不可见时显示“登录后可预览”。
- 提取图片时过滤头像、表情、站点图标和布局图片。

页面清理：

- 默认折叠大段版规。
- 默认折叠重复反诈提示。
- 默认折叠评论区。
- 保留“展开原帖”入口，用户可恢复查看完整帖子。

## 购买流程

用户点击“购买并保存到百度网盘”后：

1. 检测论坛登录态。
2. 检测资源是否已购买。
3. 如果未购买，弹出确认框。
4. 确认框展示标题、售价、余额、资源大小和保存目录。
5. 用户确认后才提交论坛购买请求。
6. 购买成功后重新解析页面或请求返回内容，提取百度分享链接和提取码。

购买策略固定为用户选择的 A 方案：每次购买前必须确认，不自动消耗软妹币。

## 百度网盘保存流程

论坛页提取到百度分享链接和提取码后，将任务写入浏览器存储，并打开百度分享页。

任务字段：

- `sourceUrl`: 原论坛帖 URL。
- `title`: 清洗后的帖子标题。
- `shareUrl`: 百度分享链接。
- `extractCode`: 提取码。
- `password`: 解压密码。
- `size`: 资源大小。
- `createdAt`: 任务创建时间。
- `targetPath`: 目标保存目录。

百度网盘页读取任务后：

1. 判断当前页面是否是任务对应分享页。
2. 如需提取码，自动填写并提交。
3. 等待文件列表加载。
4. 创建或复用目标目录。
5. 选择资源并保存到目标目录。
6. 将结果回写到任务状态。

目标目录规则采用用户确认的 C 方案：

`/老王转存/YYYY-MM/帖子标题/`

示例：

`/老王转存/2026-06/大美女【SkylarBlue】完美臀，超模身材/`

目录名处理规则：

- 去除文件系统和网盘路径中的危险字符。
- 去除标题里的资源大小、网盘类型等尾缀信息。
- 标题过长时截断到安全长度。
- 如果目录已存在，直接复用。

## 数据流

论坛页：

1. 解析 DOM，抽取主楼信息。
2. 构建增强面板和图片画廊。
3. 点击按钮后进入购买确认。
4. 购买完成后提取百度链接与提取码。
5. 写入 `localStorage` 或 `GM_setValue` 任务队列。
6. 打开百度分享页。

百度页：

1. 读取任务队列。
2. 匹配当前分享链接。
3. 自动填码。
4. 创建目标目录。
5. 保存文件。
6. 回写任务状态。

论坛页状态刷新：

- 页面获得焦点时检查任务状态。
- 如果百度页回写成功，显示“已保存到百度网盘”。
- 如果失败，显示失败原因和“打开百度页手动保存”按钮。

## 错误处理

论坛页：

- 未登录：提示“请先登录论坛后刷新页面”。
- 未购买且无法读取售价：停止购买，提示用户手动确认。
- 购买请求失败：展示论坛返回信息，不重复提交。
- 找不到百度链接：提示用户展开原帖或手动复制链接。

百度页：

- 未登录百度：提示用户登录后刷新。
- 提取码错误：标记任务失败。
- 分享失效：标记任务失败。
- 保存目录创建失败：降级为打开保存弹窗并提示手动选择目录。
- 页面结构变化：停止自动点击，提示手动保存。

## 测试计划

手动验证场景：

- 未登录论坛时，增强面板显示基础信息和登录提示。
- 登录但未购买时，点击按钮出现购买确认框。
- 取消购买时，不产生购买请求。
- 确认购买后，能提取百度链接和提取码。
- 百度未登录时，脚本提示登录，不执行保存。
- 百度已登录时，能保存到 `/老王转存/YYYY-MM/帖子标题/`。
- 目标目录已存在时，复用目录。
- 保存成功后，论坛页能显示成功状态。

代码级验证：

- 标题清洗函数。
- 字段抽取函数。
- 图片过滤函数。
- 百度链接和提取码解析函数。
- 目标目录生成函数。
- 任务队列读写函数。

## 交付物

实现阶段交付一个油猴脚本文件，建议路径：

`laowang/laowang_baidu_transfer.user.js`

脚本包含：

- 元数据头。
- 老王论坛页面模块。
- 百度网盘页面模块。
- 公共任务队列和工具函数。
- 明确的状态提示和错误降级路径。
